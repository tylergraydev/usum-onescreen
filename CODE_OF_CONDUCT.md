# Code of conduct

This project wants to be a friendly place to report bugs and build things together.

- Be respectful and assume good intent. Disagree with ideas, not people.
- No harassment, insults, discrimination or personal attacks, in any project space.
- Don't share or ask for game dumps, keys or other pirated material.
- Keep discussion on topic.

The maintainer may edit or remove comments, close issues or pull requests, and block anyone who breaks these rules. To report a problem privately, contact the maintainer through their GitHub profile ([@tylergraydev](https://github.com/tylergraydev)).
