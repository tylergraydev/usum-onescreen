# Security policy

USUM One Screen runs inside the Azahar emulator, and its Windows launcher downloads Azahar and installs files on your PC. If you find a problem that could harm a user's PC or data (for example a way to make the launcher write outside its folder, run unexpected code, or skip its download checks), please report it privately.

## Reporting

Use GitHub's **Report a vulnerability** button on the repository's **Security** tab. Please don't open a public issue for security problems.

Include what you found, how to reproduce it, and which version (release tag or commit) you tested. You should hear back within a week.

## Supported versions

Only the latest release and `main` get fixes.
